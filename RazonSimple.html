Razón simple

La razón simple de tres puntos alineados se define como:

RS(A, B, C) = AC/AB

donde los segmentos se consideran orientados. Es decir, tienen el mismo signo si los vectores AB y AC tienen el mismo sentido, y signo contrario si tienen sentido contrario. Por tanto, el orden es esencial.

Si 0 < λ < 1, el punto C se encuentra entre A y B, si es λ > 1 se encuentra más allá de B y si es λ < 0 se encuentra antes que A, en el sentido marcado por el vector AB.

Si queremos divider el segmento en la proporción AC:AB = p:q, debemos tomar λ = p/q,

C = A + p/q(B - A) = (1 - p/q)A + (p/q)B = ((q - p)A + pB)/q

Por ejemplo, para hallar el punto medio, debe ser λ = ½:

C=(A + B)/2

Para dividirlo en tres partes iguales, debe tomarse λ = ⅓, ⅔:

C₁ =(2A + B)/3, C₂ = (A + 2B)/3

O de otra forma, si se quiere dividir el segmento AB por C en la proporción AC:CB = p/q, debe ser

C=(qA + pB)/(p+q)

La razón simple de tres puntos alineados se conserva en las transformaciones afines del plano, que incluyen entre otras, traslaciones, giros y semejanzas.
